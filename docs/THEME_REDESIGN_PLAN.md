## 已确认方向

用户先要求只生成预览，否定大面积写实水彩图案，选择缩小后的「轻描纸印」，随后明确授权实装。

视觉依据：[最终确认效果图](design/light-paper-approved.png)，不是早期放大的水彩稿。

- 六种原主题：云朵、植物、小猫、纸飞机、星月、几何。
- 灰绿细线、少量淡色填充；没有猫毛、叶脉、水彩颗粒或厚重背景。
- 所有主题统一左下角，尺寸不超过 64px / 18vw，保持右下角 52px 添加按钮。
- 首页和设置页共享同一透明 PNG，资源随应用打包，离线可用。
- 视觉实装不修改日期、正文、工具入口或原生能力；后续真机收尾仅修正视口/光标定位和保存正确性，不增加新功能阶段。
