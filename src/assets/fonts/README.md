Only diary paragraphs, placeholders, and diary/draft summaries use this font.
Dates, headings and controls retain their existing fonts. Body size is `1rem`
(16 CSS px at default settings), and respects browser/system text scaling.
The font is bundled locally; no CDN requests or submission of diary text.
Unsupported characters fall back to the existing sans-serif stack. Do not
substitute the older repository-root font: its sample glyphs can be blank.
